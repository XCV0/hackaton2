# Результат прогона тестовых PDF через сервис (2026-11-21)

Режим: расширенный (A + B + нода R). Klinch вернул HTTP 402 (нет средств) для `claude-haiku-5-5` и `gpt-6-luna`, поэтому
цепочка резервов отдала **все** запросы локальному Claude Code (`claude-cli/haiku`). Значит, A и B — одна модель:
кворум здесь показывает воспроизводимость, а не независимость (в UI это отмечено как ограничение).
Официальные проверщики на экспорте demo: RAG — 0 ошибок (с OCR найдены 41/41 цитат), солнечные — 0 ошибок.

## Что было исправлено по итогам этого теста
1. Табличные значения с цитатой-меткой строки теперь проверяются геометрически (число в той же строке) — раньше все шли «на проверку».
2. Сущности сливаются между страницами по имени («HybridRet-RAG» = «HybridRet-RAG (ours)»), если остальные поля не противоречат.
3. `champion_vs_mean` сравнивает лучший прибор и среднее одной партии (по метке «(additive)»), а не только один device_id.
4. `voc_limit` работает для значения без ссылки на материал, если поглотитель в статье один.
5. Текст vs таблица: противоречие ищется и между разными «экспериментами» ноды; `duplicate_of` ставится только при полном совпадении полей проверщика.
6. `metric_variant`, повторяющий название метрики («exact match» у EM), очищается.
