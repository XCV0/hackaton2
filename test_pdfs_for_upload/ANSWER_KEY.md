## TEST_SOLAR_CIGS.pdf — солнечные элементы (CIGS), 3 страницы

Материал: Cu(In,Ga)Se2, класс **CIGS**, Eg = **1.15 eV**, метод **EQE**. Архитектура **substrate**, подложка — стекло (rigid).
Слои: Mo 500 nm (back contact) → CIGS 2.0 um = **2000 nm** (absorber) → CdS 50 nm (ETL/буфер) → i-ZnO 80 nm →
ZnO:Al 300 nm (front contact) → Ni-Al grid (front contact). Освещение AM1.5G, **1000 W/m² (= 100 mW/cm²)**, 25 °C.
Площадь: aperture 0.50 cm², total 0.55 cm² — **разные определения**.
